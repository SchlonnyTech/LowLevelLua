Versions

Release history and changelog for LLL.

v1.1.0

StableCurrent

Changes

  • Direct LLVM object file emission (no clang)
  • File IO: open, read, write, close via syscalls
  • Memory: malloc, free, memset, memcpy, alloc, realloc
  • Tables: mixed string/int with high-bit tagging, full print
  • Byte indexing on pointers with i8 to i64 zext
  • Byte comparison with integers
  • Include system with top-level statement execution
  • Keyword handlers return LLVMValueRef
  • Control flow after IO operations
  • Type inference for keyword calls without warning
