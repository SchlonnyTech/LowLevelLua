LLL is a Lua-inspired, statically-typed language that compiles straight to LLVM IR — zero C intermediate, zero dependencies beyond LLVM itself.

Core language features

13 features shipping today
01

Straight to LLVM IR

No C translation step. lllc lowers source directly to LLVM IR, then hands it to LLVM's JIT or native backend.

02

JIT or native binary

Run instantly through LLVM's ExecutionEngine while iterating, or compile into a standalone executable.

03

Structs, enums, typed locals

Static types are opt-in on top of Lua-like syntax, with struct and enum declarations.

04

Syscalls and inline assembly

Drop below the language with direct syscalls or inline LLVM assembly — both still being finished.
