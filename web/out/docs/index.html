Quick Start

Create hello.lll:

hello.lll
print("Hello, World!")

Compile (AOT):

terminal
./lllc hello.lll -o hello
./hello

JIT:

terminal
./lllc hello.lll --jit

Generate LLVM IR:

terminal
./lllc hello.lll -S

Building

Linux:

terminal
mkdir build
cd build
cmake ..
ninja

File I/O

File operations using direct syscalls:

file_io.lll
local fd: int = io.open("/tmp/lll_test.txt", 65)
io.write(fd, "LLL file write works!\n", 22)
io.close(fd)

local fd2: int = io.open("/tmp/lll_test.txt", 0)
local buf = mem.malloc(100)
io.read(fd2, buf, 22)
io.close(fd2)

if buf[1] == 76 then
    print("Write verified!")
else
    print("Write failed")
end

IO Functions Reference

io.open(path: string, flags: int): int

Open a file and return file descriptor

Parameters
path(string)File path to open
flags(int)Open flags (0=read, 65=write/create, etc.)
Returns: File descriptor as int, or -1 on error
io.close(fd: int): int

Close an open file descriptor

Parameters
fd(int)File descriptor to close
Returns: 0 on success, -1 on error
io.read(fd: int, buf: pointer, len: int): int

Read bytes from file into buffer

Parameters
fd(int)File descriptor to read from
buf(pointer)Buffer to store read data
len(int)Number of bytes to read
Returns: Number of bytes read, or -1 on error
io.write(fd: int, buf: pointer, len: int): int

Write bytes from buffer to file

Parameters
fd(int)File descriptor to write to
buf(pointer)Buffer containing data to write
len(int)Number of bytes to write
Returns: Number of bytes written, or -1 on error
io.mkdir(path: string, mode: int): int

Create a directory

Parameters
path(string)Directory path to create
mode(int)Permissions (e.g., 0755)
Returns: 0 on success, -1 on error
io.rmdir(path: string): int

Remove an empty directory

Parameters
path(string)Directory path to remove
Returns: 0 on success, -1 on error
io.unlink(path: string): int

Delete a file

Parameters
path(string)File path to delete
Returns: 0 on success, -1 on error
io.rename(from: string, to: string): int

Rename or move a file

Parameters
from(string)Current file path
to(string)New file path
Returns: 0 on success, -1 on error
io.chdir(path: string): int

Change current working directory

Parameters
path(string)Directory path to change to
Returns: 0 on success, -1 on error
io.exit(code: int): void

Exit the program

Parameters
code(int)Exit code (0 for success)
Returns: Does not return

Memory Management

Memory Functions Reference

mem.malloc(size: int): pointer

Allocate uninitialized memory

Parameters
size(int)Number of bytes to allocate
Returns: Pointer to allocated memory, or null on failure
mem.alloc(count: int, size: int): pointer

Allocate zero-initialized array

Parameters
count(int)Number of elements
size(int)Size of each element in bytes
Returns: Pointer to zero-initialized memory, or null on failure
mem.realloc(ptr: pointer, size: int): pointer

Resize previously allocated memory

Parameters
ptr(pointer)Pointer to existing allocation
size(int)New size in bytes
Returns: Pointer to resized memory, or null on failure
mem.free(ptr: pointer): void

Free allocated memory

Parameters
ptr(pointer)Pointer to memory to free
Returns: Nothing
mem.memset(ptr: pointer, val: int, len: int): pointer

Set memory to a specific value

Parameters
ptr(pointer)Destination memory
val(int)Byte value to set (0-255)
len(int)Number of bytes to set
Returns: Pointer to destination memory
mem.memcpy(dst: pointer, src: pointer, len: int): pointer

Copy memory from source to destination (non-overlapping)

Parameters
dst(pointer)Destination memory
src(pointer)Source memory
len(int)Number of bytes to copy
Returns: Pointer to destination memory
mem.memmove(dst: pointer, src: pointer, len: int): pointer

Move memory (safe for overlapping regions)

Parameters
dst(pointer)Destination memory
src(pointer)Source memory
len(int)Number of bytes to move
Returns: Pointer to destination memory
mem.memcmp(a: pointer, b: pointer, len: int): int

Compare two memory regions

Parameters
a(pointer)First memory region
b(pointer)Second memory region
len(int)Number of bytes to compare
Returns: 0 if equal, <0 if a<b, >0 if a>b

Language Overview

example.lll
-- Variables with type inference
local name = "LLL"
local version = 42

-- Explicit types
local count: int = 42

-- Functions
local function greet(person: string): string
    return "Hello, " .. person .. "!"
end

-- Structs
struct Point
    x: float64
    y: float64
end

-- Enums
enum Color
    RED = 1
    GREEN = 2
    BLUE = 4
end

-- Control flow
if score >= 90 then
    print("Excellent!")
elseif score >= 80 then
    print("Good!")
else
    print("Needs work")
end

-- Loops
for i = 1, 10 do
    print(i)
end

while count > 0 do
    count = count - 1
end

repeat
    num = num * 2
until num > 100

-- Tables (1-indexed)
local nums = {1, 2, 3, 4, 5}
print(nums[1])

Command Line Options

lllc file.lll- AOT compile to executable
lllc -S file.lll- Generate LLVM IR only
lllc --jit file.lll- JIT compile and execute
lllc -e code- Run code directly
lllc -c code- Compile code directly
lllc- Interactive mode
lllc --module file.lll- Build as shared library
lllc --x86 file.lll- Compile for 32-bit
lllc -v- Verbose mode (show LLVM IR)

Available Types

int- 64-bit signed integer
int32- 32-bit signed integer
int64- 64-bit signed integer
float32- 32-bit floating point
float64- 64-bit floating point
uint8- 8-bit unsigned integer
uint64- 64-bit unsigned integer
string- Character string
boolean- True or false
void- No type
